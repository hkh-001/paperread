# MemoryBank：让对话智能体记住、遗忘并逐步形成用户画像

> 论文：**MemoryBank: Enhancing Large Language Models with Long-Term Memory**  
> 会议：AAAI 2024  
> 原文：[[MemoryBank - Enhancing Large Language Models with Long-Term Memory.pdf]]  
> 官方页面：https://doi.org/10.1609/aaai.v38i17.29946  
> 代码与材料：https://github.com/zhongwanjun/MemoryBank-SiliconFriend

## 0. 为什么把它作为第 5 篇

第 4 篇 Generative Agents 把 observation、reflection、plan 放入统一记忆流，但只模拟两天，检索中的时间衰减主要是工程设计。本篇把视角收窄到人—AI 长期对话，集中研究三件事：长期存储、按当前问题召回、随时间遗忘与重复强化。它从“虚拟社会里的角色连续性”过渡到“真实陪伴场景里的用户连续性”，也为后面的情感支持论文准备了个性化与心理学背景。

难度：中等偏易。公式只有一个核心指数衰减式，真正需要批判阅读的是：心理学概念被怎样简化成工程规则，以及实验是否真的证明了“长期陪伴”。

## 1. 三种粒度的摘要

### 一句话

MemoryBank 用原始对话、层级事件摘要和用户画像构成外部记忆库，并以 embedding 检索和受艾宾浩斯遗忘曲线启发的记忆强度更新，为 LLM 提供跨会话个性化上下文。

### 三句话

1. 普通聊天模型依赖有限上下文，跨天后难以记住事件、偏好和人格线索。
2. MemoryBank 保存逐日对话，生成日级/全局事件摘要和人格画像；被召回的记忆强度增加，未被强化的记忆按指数规律降低保留率。
3. 作者将其用于 SiliconFriend，在 10 天、15 个模拟用户、194 个中英记忆问题上评估三个底座，但实验主要测召回与回答质量，并不足以证明拟人遗忘或真实心理陪伴的长期有效性。

### 一段话

系统把每轮用户—助手对话与时间戳写入 memory storage，并由 LLM 压缩为每日事件、全局摘要及用户人格/情绪画像。新问题到来时，通过向量相似度找到相关历史，把相关记忆、用户画像和当前对话共同放入提示。每条记忆具有强度 $S$ 与距上次强化的时间 $t$，保留率用 $R=e^{-t/S}$ 计算；当记忆被再次召回时，$S\leftarrow S+1,t\leftarrow0$。SiliconFriend 还用 3.8 万条心理对话微调，以改善情感支持表达。

## 2. 问题、动机与研究缺口

### Task

让 LLM 在跨日、跨会话的陪伴中能够：

- 找回过去谈过的事实；
- 总结事件而非无限保存全部上下文；
- 理解用户长期偏好、人格与情绪；
- 选择性遗忘不常使用的信息；
- 用这些记忆生成连贯、个性化的回应。

### 直观例子

第 1 天用户说：“女朋友喜欢梵高，我下周要准备生日礼物。”第 8 天问：“你还记得她喜欢什么吗？”无外部记忆的模型只能猜；简单关键词库可能找回“梵高”，却不知道这是女朋友的偏好；MemoryBank 希望同时找回事件关系和用户画像，并在长期未提及时逐步降低该条记忆被保留的概率。

### Previous Work 与 Gap

短上下文聊天、固定 persona 或单会话摘要无法覆盖持续交互。向量数据库能找相似文本，但通常不建模“重复回忆后更稳固、时间久后更易忘”。本文主张：**存储—检索—更新三位一体的外部模块，可以不改闭源 LLM 参数就增强长期个性化。**

## 3. 架构与信息流

```text
历史对话 + 时间戳
   │
   ├─ 原始逐轮对话
   ├─ 每日事件摘要 → 全局摘要
   └─ 人格与情绪画像
          ↓
      Memory Storage
          │ embedding 检索 + 遗忘筛选
当前问题 ─┤
          ▼
相关记忆 + 用户画像 + 当前历史 → LLM → 回应
          │
          └─ 若记忆被召回：S += 1，t = 0
```

| 循环 | 时间尺度 | 是否更新模型参数 |
|---|---|---|
| 当前回答 | turn | 否，仅读取检索上下文 |
| 事件汇总 | day / 多轮 | 否，由 LLM 生成摘要后外存 |
| 画像更新 | 多轮/跨日 | 否，更新文本画像 |
| 遗忘与强化 | cross-session | 否，更新记忆元数据 $S,t$ |
| 心理对话微调 | training time | 是，仅 SiliconFriend 开源底座版本 |

必须区分：MemoryBank 是可插拔外部记忆；SiliconFriend 是“MemoryBank + 底座 LLM + 心理对话微调”的应用实例。

## 4. 三层记忆表示

### 4.1 原始对话

保存逐日对话和时间戳，细节最完整但噪声最大。它适合回答“你当时推荐了哪本书”，却不适合直接全部放入上下文。

### 4.2 层级事件摘要

先把一天内冗长对话压缩成关键事件，再把多日事件综合为全局概括。层级压缩降低 token 成本，也可能丢掉否定、条件、时间顺序和说话者来源。

### 4.3 用户画像

用提示让 LLM 总结 personality traits 和 emotions。画像帮助同一问题对不同用户给出不同建议，但它是模型推断，不是临床诊断，也不应与用户明确自述混为一谈。工程上应保存：`claim/source/confidence/last_updated/consent`。

## 5. 检索机制

论文使用语义向量检索：把当前 query 和记忆编码到向量空间，通过相似度选相关条目。可用余弦相似度理解：

$$
\operatorname{sim}(q,m)=\frac{\mathbf e_q^\top\mathbf e_m}{\|\mathbf e_q\|_2\|\mathbf e_m\|_2}
$$

这是教学性表达；论文重点描述整体机制而未对检索公式进行新推导。相关性检索的盲点包括：同义表达可能匹配，事实冲突不一定被识别；“最近状态”与“最相似旧状态”可能相反；相似并不代表应该向用户重提敏感信息。

## 6. 艾宾浩斯启发的遗忘公式

论文给出：

$$
R=e^{-t/S}
$$

- $R\in(0,1]$：memory retention，论文将其解释为信息被保留的比例/概率式指标；
- $t\ge0$：距学习或上次强化经过的时间；
- $S>0$：memory strength；首次提及时初始化为 1；
- $e\approx2.71828$。

当记忆在对话中被召回：

$$
S\leftarrow S+1,\qquad t\leftarrow0
$$

### 6.1 数值直觉

若 $S=1$：$t=1$ 时 $R=e^{-1}\approx0.368$；$t=3$ 时约 0.050。若同一记忆多次被召回到 $S=3$，在 $t=3$ 时 $R=e^{-1}\approx0.368$。所以更强的记忆曲线下降更慢。

偏导数进一步帮助理解（以下为教学性展开，并非论文推导）：

$$
\frac{\partial R}{\partial t}=-\frac{1}{S}e^{-t/S}<0,\qquad
\frac{\partial R}{\partial S}=\frac{t}{S^2}e^{-t/S}>0
$$

时间增加会降低保留率；强度增加会提高保留率。

### 6.2 关键假设与边界

- $t$ 的单位和删除阈值会实质改变系统行为，论文没有建立个体化校准。
- 每次召回统一加 1，默认所有复习同等有效，也不区分“用户纠错”和“模型误提”。
- 重要但少提的敏感事实可能被忘掉；频繁误检的错误记忆反而被强化。
- 人类遗忘曲线来自受控记忆实验，把它直接映射到对话事件是启发式类比，不是认知模型验证。

## 7. SiliconFriend：陪伴应用而非新底座模型

作者在 ChatGPT、ChatGLM、BELLE 三类底座上接入 MemoryBank。开源版本还使用从网络来源收集的约 38k 心理对话进行参数高效微调，目标是让回答更有同理心、谨慎和支持性。需要把两种效果拆开：

- 记住书名、过去事件：主要来自 MemoryBank；
- 回应更温和、更像支持对话：可能来自底座能力、心理数据微调和提示；
- 论文没有完整的因子消融证明三者各自贡献。

## 8. 实验协议

### 8.1 定性分析

作者展示真实用户对话案例，比较基线和 SiliconFriend 的情感支持、历史召回与按人格推荐。案例能说明可行性，却不能估计总体效应，也可能经过选择。

### 8.2 定量记忆实验

- 10 天模拟对话；
- 15 个由 ChatGPT 扮演、人格各异的虚拟用户；
- 每天至少覆盖两个话题；
- 194 个研究者手写 probing questions：英文 97、中文 97；
- 比较 SiliconFriend-ChatGLM、SiliconFriend-BELLE、SiliconFriend-ChatGPT。

### 8.3 指标

1. Retrieval Accuracy：是否检索到相关记忆，0/1。
2. Response Correctness：错误 0、部分正确 0.5、正确 1。
3. Contextual Coherence：不连贯 0、部分 0.5、连贯 1。
4. Ranking：三个系统相对名次 $r\in\{1,2,3\}$，得分 $s=1/r$。

$s=1/r$ 意味着第 1 名 1 分、第 2 名 0.5、第 3 名约 0.333。它强调第一名，但不是差距等距的质量分。

## 9. 主要结果

| 语言 | 模型 | Retrieval | Correctness | Coherence | Ranking |
|---|---|---:|---:|---:|---:|
| English | ChatGLM | 0.809 | 0.438 | 0.680 | 0.498 |
| English | BELLE | 0.814 | 0.479 | 0.582 | 0.517 |
| English | ChatGPT | 0.763 | **0.716** | **0.912** | **0.818** |
| Chinese | ChatGLM | 0.840 | 0.418 | 0.428 | 0.510 |
| Chinese | BELLE | **0.856** | 0.603 | 0.562 | 0.565 |
| Chinese | ChatGPT | 0.711 | **0.655** | **0.675** | **0.758** |

### 怎样解释

- ChatGPT 的检索命中不是最高，但正确性、连贯性和总体排名最好：**检索到记忆与正确使用记忆是两个阶段。**
- BELLE 在中文检索最高，不代表最终回答最好。
- 该表没有“无 MemoryBank”的同预算对照，因此主要比较接入同一框架后的底座，不足以量化 MemoryBank 相对无记忆的提升。
- 论文未报告置信区间、标注者一致性和显著性检验，0.02–0.05 的差异不能轻易解释为稳定优势。

## 10. 消融、案例与不足

论文声称考察有/无遗忘机制的适用性，但主文的核心定量表并未给出一个完整的 `no memory / retrieval only / +summary / +portrait / +forgetting` 因子消融矩阵。这是复现时最需要补齐的部分。

正面案例包括回忆此前推荐的 Python 书、记得写过 quicksort、正确否认讨论过 heap sort；个性化案例根据内向且重视成长的 Linda 推荐文化和新技能活动，而对兴趣更广的 Emily 给出更开放建议。案例支持系统能引用画像，但不能排除提示直接暴露画像导致的表面适配。

## 11. 贡献与局限

### 贡献

- 用统一接口把原始对话、摘要、画像和动态更新接到闭源/开源 LLM；
- 将“遗忘—复习强化”引入长期对话记忆设计；
- 同时覆盖中英文和多个底座；
- 将记忆与情感陪伴场景结合，贴近人机共生应用。

### 作者承认

遗忘模型是高度简化的探索性设计；真实记忆受材料意义、个体差异、过度学习等更多因素影响。

### 进一步推断

- 对话由 ChatGPT 模拟，可能比真实用户更规律、与评测模型语言分布更接近。
- 10 天仍是短期；没有测试数月冲突、身份变化和错误累积。
- 用户画像可能固化刻板印象；“内向”一旦写入提示会反复影响推荐。
- 遗忘不是隐私删除：向量、摘要、日志、备份可能仍保留内容。
- 论文没有充分评价敏感记忆重提、用户控制权、依赖和危机应对。
- 心理对话数据来源与质量会影响安全；同理措辞不等于临床有效。

## 12. 与前文和实验室方向的关系

| 比较 | Generative Agents | MemoryBank |
|---|---|---|
| 对象 | 虚拟角色自身经历 | 用户—助手历史与用户画像 |
| 时间 | 两天模拟 | 10 天模拟对话 |
| 时间信号 | recency 参与排序 | retention 决定遗忘/强化 |
| 高层表示 | reflection tree | 日摘要、全局摘要、人格画像 |
| 目标 | 行为可信与社会涌现 | 召回、个性化与陪伴 |

对实验室最直接的价值：长期多轮交互、人格/情绪建模、个性化 RAG、心理理论向 Agent 机制的迁移。它部分涉及主体连续性的外在表现，但**不研究主观性或意识**。在人机共生系统中，应该加入用户可见的记忆面板、纠错、禁存、过期与彻底删除机制。

## 13. 最小复现蓝图

### 组件

```python
for session in conversations:
    store(raw_turns=session, timestamp=now)
    daily_summary = llm_summarize(session)
    portrait = llm_update_portrait(previous_portrait, session)

for query in user_queries:
    candidates = vector_search(query)
    alive = [m for m in candidates if retention(m) >= threshold]
    answer = llm(query, portrait, alive)
    for m in alive:
        m.strength += 1
        m.elapsed = 0
```

## 16. 概念速查

| 概念 | 含义 | 风险 |
|---|---|---|
| Event summary | 对话的压缩事件表示 | 细节与否定丢失 |
| User portrait | 从历史推断的人格/情绪 | 刻板化、未经同意 |
| Retrieval | 按语义找相关记忆 | 相似≠最新/真实/适合提及 |
| Strength $S$ | 记忆强化程度 | 错误召回也可能被强化 |
| Retention $R$ | 指数式保留指标 | 非真实认知概率校准 |
| SiliconFriend | 应用系统 | 不等于 MemoryBank 本身 |

## 17. 常见误解

- “公式证明系统像人一样遗忘”——只是借用曲线形状的启发式实现。
- “检索率高，回答就一定正确”——表 2 恰好显示二者可分离。
- “画像等于用户真实人格”——画像是模型对有限对话的推断。
- “加入心理对话数据就能做心理咨询”——论文未验证临床安全和疗效。
- “忘记机制实现了隐私权”——工程遗忘与彻底删除是不同问题。

## 20. 长期记忆锚点

1. MemoryBank = 存储 + 检索 + 更新，不是新基础模型。
2. 存储含原始对话、层级事件摘要和用户画像。
3. 核心式 $R=e^{-t/S}$；召回后 $S+1,t=0$。
4. 实验规模：10 天、15 个虚拟用户、194 问（中英各 97）。
5. 检索成功与回答正确必须分开评估。
6. 心理学启发不等于心理学验证；同理表达不等于临床有效。
7. 下一步需要学习情感支持任务本身，以及更严格的长期记忆基准。
