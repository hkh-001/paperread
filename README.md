## 如何记录阅读过程

1. 每篇论文放在独立文件夹中，保留 PDF 和 Markdown 阅读笔记。
2. 在笔记中更新 `date_read`、`status`，并补充自己的理解、疑问、复现结果和后续想法。
3. 每次有实质进展后提交一次，让 Git 历史记录学习过程。

在此目录打开终端执行：

```bash
git status
git add .
git commit -m "阅读进展：论文名与本次收获"
git push
```

首次提交保存当前已有材料，历史阅读日期以笔记中的记录为准。关联仓库后，文件修改需要 commit 和 push 才会同步到 GitHub。
