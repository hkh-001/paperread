# 上下文隔离修正后：十题三组重跑报告

日期：2026-10-23。同一批调试题重新运行 direct / CoT / ReAct，保留全部 30 次作答，不挑选或补跑结果。

## 修改范围与验证

本轮只修改上下文接纳顺序及审计标记：先解析动作和校验方法格式；通过后才把模型输出加入上下文。格式错误的原始输出仅保存在 trace，写入 `accepted_to_context=false`，后续模型只收到原有格式错误提醒。合法输出标记为 true，工具执行后的真实 Observation 才加入上下文。

未修改提示词、错误提醒文字、检索工具、评分、题目、顺序、模型、temperature、内置思考开关或步数/输出上限。配置逐字段核对通过；代码哈希不同。

12 项测试通过；新测试覆盖自行生成 Observation、多动作、缺少 Thought、Act-only 违规，以及连续非法输出。请求快照断言被拒绝的原文不在后续请求中，原始日志仍保留它；合法 Search 产生的实际证据会进入下一次请求。

这个修复保证被解析器识别并拒绝的非法输出不再被重新传入，不能保证检测到模型在自然语言中作出的所有无依据断言。它不强迫每题调用工具，也不保证模型不会直接猜答。

- 修正前：4 道题出现被拒绝的自行生成 Observation；2 道题正确但没有实际检索动作。
- 修正后：5 道题出现被拒绝的自行生成 Observation；0 道题正确但没有实际检索动作。

修正后仍可能出现非法输出，修复的是它们不能进入下一轮上下文。即使模型随后直接给出同一个答案，也不能只凭结果相同判断其读取了已隔离的文字；需要根据实际发送的请求验证边界。没有调用工具的正确答案仍应标为凭模型自身输出作答，不宣传为检索证明。

## 本轮最清楚的一项变化

`react-dev-03824`（David Chanoff / 海军上将 / 总统）和 `react-dev-02544`（两者国籍是否相同）在旧版中都先生成了一段未经执行的多步搜索，然后直接 Finish，实际检索为 0。

本轮两题的第一段模拟搜索仍被拒绝，但后续不再接收这段内容。轨迹显示，两题随后各执行 2 次真实 Search，再提交正确答案。得分没有增加，执行过程却更符合我们要验证的工具交互规则。

本轮 ReAct 的六道正确题均执行过真实检索动作；这不代表推理每个环节都已被完全证明，也不能由此断定所有答案都因检索才答对。仍应逐题检查证据。

整体得分仍为 6/10：期刊题从步数耗尽变为提交 1931，仍不匹配参考答案；Hardley Flood 题仍耗尽步数，另有两题在维基检索中遇到 HTTP 429。本轮 CoT 为 6/10（上一轮 8/10），direct 仍为 4/10，进一步说明单轮小样本结果会波动。
