## 如何解释本轮验证

本轮十题没有因工具错误结束，而上一轮有两题遇到工具限流。这说明改进后的检索在本轮端到端运行中能够完成请求；样本小、服务器负载与模型路径变化，不能由此保证之后永远没有工具故障。

答案得分的变化不能全部归因于检索层。模型仍可能选择不同路径，在线资料和缓存也会影响返回内容；这里只能报告观察到的差异。
没有实际调用工具的正确答案仍属于模型自身作答，不应宣传为检索验证。被拒绝的自行生成 Observation 保留在日志中，仍被隔离出后续上下文。

本轮 ReAct 答对 6/10，答案 F1=0.644；8 题正常提交，2 题达到步数上限。32 次真实 HTTP 请求均未失败，0 次 429，0 次额外重试，4 次缓存命中。没有发生需要退避恢复的真实故障，因此这轮端到端运行验证了正常路径和缓存路径，不能代替此前模拟 429 的测试。
