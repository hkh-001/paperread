## 如何看 supporting facts

打开 [原始支持证据.json](原始支持证据.json)，查看 row.supporting_facts。

- title 与 sent_id 按位置一一对应。
- sent_id 从 0 开始，0 是第一句，1 是第二句。
- 到 row.context.title 找对应标题，再到相同位置的 row.context.sentences 中取出指定句子。
- 这些编号对应数据集保存的段落，不是今天实时网页上的句子编号。

## 这道题的证据链

1. New York Botanical Garden，第 0 句：纽约植物园位于布朗克斯。
2. Mycologia，第 0 句：Mycologia 是发表真菌相关研究的科学期刊。
3. Mycologia，第 1 句：该刊由纽约植物园出版，于 1909 年 1 月首次出版。

因此，参考答案的路径是：

**布朗克斯 → 纽约植物园 → Mycologia → 1909 年。**

模型实际走的是：

**布朗克斯 → 纽约植物园 → Brittonia → 1931 年。**

两条路径的分歧在期刊对象。工具支持 Brittonia 的创刊年份，但模型没有确认它就是数据集所指的期刊。

原始 distractor 样本包含十个候选段落，目标期刊可从这些段落中定位；我们的开放检索实验只给问题，没有提供这些段落。因此，也应承认实验设置不同，不能据这一题把对象选择错误完全归因于 ReAct 机制。
