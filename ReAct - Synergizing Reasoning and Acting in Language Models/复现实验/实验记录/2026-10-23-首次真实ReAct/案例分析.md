# 首次 ReAct 案例分析

日期：2026-10-23。依据已完成的真实轨迹及原始支持证据整理，由用户确认采用这份分析作为本次学习记录。

## 实验现象

问题要求查询：由一家位于布朗克斯的机构出版的科学期刊，首次出版于哪一年。模型运行了 5 步，执行 4 次检索/查找，最终回答 1931；HotpotQA 参考答案为 1909。

模型通过搜索找到了位于布朗克斯的纽约植物园，随后搜索 Brittonia，检索到该刊自 1931 年开始出版。程序正常结束，但答案与参考标注不一致。

## 缺少证据的步骤

第 3 步 Lookup[journal] 返回的是图书馆收藏期刊的信息，没有确定纽约植物园出版的目标期刊。第 4 步模型就选择了 Brittonia；该名称此前没有出现在工具返回中，因此属于模型提出的候选，尚未被确认为题目指向的对象。

检索支持“Brittonia 的创刊年份是 1931”，却不足以证明“本题问的就是 Brittonia”。原始支持证据指向的是 Mycologia，首次出版时间是 1909 年。两条路径在期刊对象的选择上分歧。

## 为什么仍然能够结束

ReAct 循环提供了工具交互能力，但本项目的程序只检查动作格式，并执行 Finish。它不会自动证明证据链是否完整，也不负责判断是否存在其他候选。finished 表示模型提交了答案，不表示答案正确或已被充分验证。

模型把一个有真实证据支持的局部结论，当成了整道题的答案。这说明检索事实正确与回答对象正确是两个不同的问题。

## 可以验证的改进假设

提交前要求核验“机构位置、期刊名称、出版关系、创刊年份”，并在机构可能关联多本期刊时检查其他候选，可能减少过早锁定对象的错误。

这只是待验证的假设。本轮 10 道题对照保持原提示词不变，先观察同类问题是否反复发生，再决定是否修改。后续若修改，不能把 Mycologia 或 1909 直接写入通用提示词。

## 局限

原题描述没有直接给出期刊名称。HotpotQA 原始 distractor 样本提供十个候选段落，本次开放检索实验没有提供这些段落，因此存在实验设置差异。不能凭这一个案例断言模型在任意解释下都错误，或判断 ReAct 整体有效性；可以确定的是其答案与该数据集的参考证据链不一致。

## 学习收获

工具返回的信息可以真实，但模型仍可能沿错误对象的路径作答。完整轨迹使我们能定位错误发生在对象识别，而不只是看到最后一个错误年份。下一步应运行一批固定题目的方法对照，区分个例与重复出现的问题。
