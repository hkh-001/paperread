# 五十题冻结评测：direct / CoT / ReAct

日期：2026-10-24。代码、提示词与参数在评测前冻结，在预留的 50 道题上完成三组共 150 次作答。未按结果修改设置、选择性补跑或替换题目。

## 评测边界

- eval50 与 dev10 不重叠，ID 清单和数据哈希已核对。题集来自 ReAct 作者的 HotpotQA 简化开发集；这不是 HotpotQA 隐藏测试集，也不是训练污染已排除的题集。
- 模型 deepseek-flash，temperature=0，内置思考关闭，每次最多 1024 输出 token；ReAct 每题最多 7 次模型调用。
- 三组使用同一模型、题目和顺序。ReAct 可以调用工具，总计算量与两种单次回答基线不同。
- ReAct 使用实时英文维基百科及共享缓存，不提供数据集原始候选段落或 supporting facts。共享缓存已有之前调试和工具验证时取得的百科响应，但没有参考答案字段；命中时间和来源可审查。
- 上下文隔离修复与检索稳定性设置均沿用上一轮：1.5 秒间隔、3 次额外重试、90 秒查询预算、7 天共享缓存新鲜期。
- 本轮不与原论文的模型、检索实现或分数直接等同；属于现代模型下的小规模方法评测。

## 这轮结果说明什么

在本批五十题上，ReAct 的 EM 为 46%，高于 CoT 的 38% 和直接回答的 36%。同题配对中，CoT 答对的十九题，ReAct 全部答对；ReAct 另答对四题。与直接回答相比，ReAct 独自答对七题，直接回答独自答对两题，净多五题。

这支持“本次检索交互在部分题目上有帮助”的观察，但不证明 ReAct 普遍优于 CoT，也没有隔离提示长度、总模型调用量、训练记忆和检索知识等因素。三组固定的是模型 ID 与请求参数，没有锁定服务端权重快照。

ReAct 使用 210 次模型调用，另两组各 50 次；ReAct 的输入/输出 token 合计 114084，明显高于 direct 的 5195 和 CoT 的 9089。它付出了更高开销，且有十题达到步数上限，没有提交答案。137 次真实检索 HTTP 请求全部成功，429 与额外重试均为 0；本轮没有工具故障，剩余失败更适合从目标识别、检索策略、步数和答案范围分析。

所有二十三道 ReAct 正确题都执行过实际工具查询。二十次格式错误被保留并隔离，不能把这些未经执行的文字当成真实证据。此次 CoT 的一题输出了两条 Final 答案行，被严格解析器判为格式失败，按零分计入。该响应 completion_tokens=442、finish_reason=stop，并非长度截断。

这五十题现已用于评测并查看结果，后续若根据它们修改方法，应把它们作为已知分析样本；不能再把同一批题称为未见过的独立验证集。下一步宜先做错误分类与案例阅读，若要测试改进，应预留新的不重叠题目。
