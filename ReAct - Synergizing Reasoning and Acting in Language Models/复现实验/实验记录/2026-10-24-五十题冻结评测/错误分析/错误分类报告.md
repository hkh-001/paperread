# 五十题评测后的错误分类与案例分析

日期：2026-10-24。分析对象为已完成的冻结评测：direct 18/50、CoT 19/50、ReAct 23/50。**原始 EM/F1、原始作答和配置均未修改；没有重新调用模型，也没有事后补跑。**

## 先看结论

ReAct 的 27 道 EM 未匹配不能直接理解成 27 道事实完全错误。我们观察到：未提交、表达与标注范围差异、实时资料冲突，以及真正的对象/关系偏离等不同情况。

本轮最值得保留的认识是：**工具可用、证据真实、对象正确、关系判断正确、答案表达符合评分规则，是不同层面的要求。** 一项通过并不保证其他项通过。

## 分类口径与依据

- 已检查三组全部 150 份记录，并保存 [三组九十份未匹配索引](三组未匹配索引.csv)。
- 对 ReAct 的 27 道未匹配作细粒度逐题核查；direct/CoT 作为同题对照，不凭一段模型解释推断其内部知识过程。
- 事后从 hotpotqa/hotpot_qa 的 validation/distractor 取得五十题原始 context 与 supporting_facts，题目和参考答案逐条一致。数据未进入此前冻结评测。
- 原始证据及来源保存在 [原始支持证据](原始支持证据.json)；[逐题错误核查](逐题错误核查.md) 展示二十七题的证据句、轨迹入口和分析。
- 每道 ReAct 未匹配题只分配一个主类别，合计 27；副标签可重复，标记协议、信息版本、状态误用等交叉问题。
- “步数耗尽”是可观察的终止现象，不是证明“只要多给步数就能答对”。归因均基于可见轨迹，不能当作对模型内部机制的因果证明。

## ReAct 主分类

| 排查主类别 | 题数 | 占 27 道未匹配 | 应如何理解 |
| --- | --- | --- | --- |
| 步数耗尽、未提交 | 10 | 37.0% | 包含搜索偏航、信息缺失、协议损耗、状态误用、已找到证据但未结束等 |
| 表达或答案范围差异 | 9 | 33.3% | 不代表九题全正确；包括别名、数字形式、简称、限定词与不完整列表等 |
| 题意、关系或证据误读 | 4 | 14.8% | 答非所问、把相关领域当理论来源、所属关系与反对关系混淆等 |
| 实时与标注数值差异 | 2 | 7.4% | 真实工具返回和原始标注给出不同数字，不直接等于模型编造 |
| 同名实体选错 | 1 | 3.7% | 把 Andrew Preston 的另一位同名人物代入比较 |
| 题面与答案类型冲突 | 1 | 3.7% | 题面问学校，参考给歌剧名，需要标注审查 |

一些步数耗尽题同样有实体混淆或题意问题，因此不能读成“全部二十七题中只有一道实体错误”。这里采用排查主类别与多重副标签，避免把可交叉原因强行当作互斥根因。

## 三个最重要的横向发现

### 1. EM 有明显的表达敏感性

三条特别清晰的审查例子：

- Psych 与 Psych is an American detective comedy-drama：原始证据指同一剧名。
- 3 与 three official languages：原始支持句明确为三种官方语言。
- Tiffany & Co. 与 Tiffany’s：原始支持句明确指出后者是前者的俗称。

另六题包括公园名称缺方位、球队缺赛季、lime/lime juice、称号简称、语言列表范围与 dice/a pair of dice，不能一概当成严格等价。

**本报告不计算“人工修正后准确率”。** 若未来要加语义评分，应先冻结别名/数字/范围规则，做人工复核或独立双人标注，并与原 EM 并列报告。不能看完这批答案后逐题放宽规则再宣称方法更好。

### 2. 检索成功不代表对象与关系正确

- Andrew Preston 题：查询返回商人 1846 年与歌手 James Taylor 1948 年；比较可自洽，但原始题目标注的 Andrew Preston 是歌手同父异母的弟弟，1983 年出生。
- Postcolonialism 题：模型用 overlaps with critical theory and cultural studies 回答理论来源；标注要求 drawing from postmodern schools of thought。页面相关不等于关系相同。
- US Navy 数值题：模型忠实使用真实返回的 336,978，旧段落却为 322,421。这应先调查数据日期和口径，而不是直接说模型幻觉。

### 3. 有预算不等于会合理停止

Gary Sinise 题第 4 步已看到 Academy Award，第 5 步再次确认，模型却增加“提名必须来自 Ransom”这一题目没有要求的限制，继续查到步数耗尽。

四道题出现了失败 Search 后继续 Lookup，得到 No current page：01439、01720、06709、07174。当前工具在 Search 未命中后清空页面，是既定语义；模型未正确管理状态。这些无效步骤可观察，但不能保证修改提示后就一定省回正确答案。

ReAct 总计 17 道题出现过格式拒绝，共消耗 20 次模型调用。它们均已隔离出后续上下文；隔离修复了证据边界，但没有消除模型自行续写整段轨迹的倾向。

## 三组配对能说明什么

| 同题模式（direct / CoT / ReAct） | 题数 |
| --- | --- |
| 三组都精确匹配 | 15 |
| 只有 ReAct 精确匹配 | 3 |
| CoT 和 ReAct 匹配，direct 未匹配 | 4 |
| direct 和 ReAct 匹配，CoT 未匹配 | 1 |
| 只有 direct 匹配 | 2 |
| 三组都未精确匹配 | 25 |

所以 ReAct 相对 CoT 多答对四题，其中三题两种基线均未匹配。也有直接回答正确、ReAct 却失败的反例。工具不是对每道题都有增益；更高总体成绩同时伴随更高开销。

## 下一步建议：先做一个小改动的探索实验

1. **先确定评价边界。** 原 EM 保留；把别名、数字和参考范围问题作为独立审查结果，不偷偷改分。
2. **若继续改实现，优先验证工具状态提示。** 每次 Search/Lookup 明示当前 page，以及失败 Search 会清空 page；先在已知调试题上看 No current page 是否减少。它是具体可测的一项改动，不与加步数、换模型同时做。
3. **再单独研究停止条件或协议输出。** 对“证据已满足目标但继续搜索”的题，测试是否能减少无必要动作；对整段模拟输出，可探索结构化动作格式。不要把某道题答案直接写进通用规则。
4. **验证改进要用新题集。** 这五十题已被用于分析，之后只能称已知分析集。冻结新版本后，再用与已有六十题不重叠的新题目验证。

本次仅做分析，没有实施这些新改动，也没有运行新的模型实验。
