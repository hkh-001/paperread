# ReAct 小规模复现教程

这套代码适合第一次做 LLM Agent 实验：先跑通交互，再用固定题集比较直接回答、CoT 和 ReAct。无需训练模型，也不需要安装 Agent 框架。Python 3.9 及以上即可，运行代码只用标准库。

## 1. 本次复现的范围

目标是验证一个机制：模型能否根据问题规划检索，根据实际返回的证据调整后续行动，最终给出答案。

| 项目 | 本项目设置 |
| --- | --- |
| 任务 | HotpotQA 多跳问答；另附一道虚构题供调试 |
| 方法 | direct、cot、react；可选 act-only |
| 模型 | 由你填写模型名和兼容 Chat Completions 的接口 |
| 工具 | Search、Lookup、Finish |
| 规模 | 1 道跑通 → 10 道调试 → 50 道评测 |
| 指标 | 答案 EM / token F1、调用次数、异常和耗时 |

这是**更换模型、提示词和检索实现的小规模方法复现**。官方代码使用旧式 Completion 接口，公开 notebook 的模型为 `text-davinci-002`；论文主实验使用 PaLM-540B。官方 HotpotQA 示例评测 500 道题。本项目提供自行编写的一条虚构 few-shot 示例，用多轮消息替代原始续写提示，在线工具使用 MediaWiki API 替代网页解析。不能将本项目分数直接与论文表格等同。

原始代码核对版本：`ysymyth/ReAct@6bdb3a1fd38b8188fc7ba4102969fe483df8fdc9`。

## 5. 配置真实模型

```bash
cp .env.example .env
```

用文本编辑器打开 `.env`，填写：

```dotenv
LLM_BASE_URL=https://你的服务地址/v1
LLM_API_KEY=你的API密钥
LLM_MODEL=服务商提供的准确模型ID
LLM_TOKEN_FIELD=max_completion_tokens
LLM_TEMPERATURE=0
```

- `LLM_BASE_URL` 填接口根地址，代码会自动追加 `/chat/completions`。不要填聊天网页地址。
- 本项目调用文本 Chat Completions 接口，不使用原生 function calling；服务必须支持 `messages` 输入和 `choices[0].message.content` 输出。
- 真实 OpenAI 服务根地址为 `https://api.openai.com/v1`；其他兼容服务填写其官方文档提供的地址。
- 某些兼容服务使用 `max_tokens`，此时改 `LLM_TOKEN_FIELD=max_tokens`。
- 模型若不支持 `temperature=0`，改 `LLM_TEMPERATURE=omit`，三组保持同样设置。
- 首次可设 `--max-tokens 1024`。若模型把输出预算消耗在内部推理，可能没有可见内容；根据该模型文档提高上限，并将预算变化记入报告。
- `.env` 自动加载，已有终端环境变量优先。改了文件却不生效时，检查是否之前 export 过同名变量。
- `.env` 已被 Git 忽略，不要把密钥填进 Python 或笔记。

### 本机 DeepSeek 配置

## 6. 准备 HotpotQA 题集

交付时，本机已完成作者数据下载及 dev10/eval50 的划分，可以直接跳到第 7 节。以下命令用于换机器或重建；若提示文件存在，保留现有文件或换目标文件名，不要重复覆盖。

默认下载 **ReAct 作者仓库发布的 HotpotQA 简化开发集**（固定源码提交版本）：

```bash
python3 react_lab.py download
```

保存到 `data/hotpot_dev_react.json`。文件只包含问题、答案与题型，共 7405 道题。原文件没有 HotpotQA 的原始 ID，程序添加 `react-dev-00000` 形式的 ID，同时保留 `source_index`；这些 ID 对应作者文件的原始行序号。来源、数据变换与哈希另存为 `.source.json`。

作者文件的 [固定版本下载地址](https://raw.githubusercontent.com/ysymyth/ReAct/6bdb3a1fd38b8188fc7ba4102969fe483df8fdc9/data/hotpot_dev_v1_simplified.json) 可供核对。网络失败时检查代理后重试，不会自动切换第三方数据源。

如希望保留 HotpotQA 原始 ID，也支持单独下载原始开发集：

```bash
python3 react_lab.py download --source hotpot
```

原始开发集约 44 MB，保存为 `data/hotpot_dev_distractor_v1.json`。原始站点可能连接失败，届时从 [HotpotQA 官方主页](https://hotpotqa.github.io/) 点击 **Dev set (distractor)** 手动下载，并在后续 `prepare --source` 中填写该文件路径。两种数据来源选择一种即可，报告中注明。

本项目**不把候选段落或 supporting facts 交给模型**；在线环境中的证据由搜索工具取得。因此这是使用开发集问题的开放检索实验，不是标准“给定十段上下文”的 distractor 阅读理解评测，也不等同于完整官方 fullwiki 基准协议。

固定同一个随机种子，取不重叠的调试集和评测集：

```bash
python3 react_lab.py prepare --source data/hotpot_dev_react.json --dest data/dev10.json --seed 233 --offset 0 --limit 10
python3 react_lab.py prepare --source data/hotpot_dev_react.json --dest data/eval50.json --seed 233 --offset 10 --limit 50
```

`prepare` 会保存题目 ID、文件哈希和采样参数，并移除上下文与 supporting facts。标准答案只由评分部分使用，不进入模型消息或检索环境。

数据遵循 HotpotQA 的 CC BY-SA 4.0 许可。大数据文件和抽样文件默认不提交；需要分享数据时，请保留来源、许可和变更说明。

## 7. 先跑一道真实题，再调试十道

需要同时能访问模型服务和英文维基百科。

```bash
python3 react_lab.py run --data data/dev10.json --env wiki --methods react --limit 1 --out runs/04-wiki-one --verbose
```

检查没有空 Observation、没有把模型生成的内容当作搜索结果，再执行：

```bash
python3 react_lab.py run --data data/dev10.json --env wiki --methods direct cot react --limit 10 --out runs/05-dev10
```

`run` 也会按 seed 打乱输入题集，但各方法始终使用相同顺序与 ID，实际顺序记录在 manifest。不要用 `run --offset` 从不同已抽样文件推断分割；集合划分以 `prepare` 输出 ID 为准。

在线工具的规则：

- Search 先尝试精确标题，跟随重定向；命中后只返回前五句，长观察会截断到 4000 字符。
- 标题未命中时返回候选标题，模型需要再次 Search。
- Lookup 在最近一次成功 Search 的完整页面中逐条查找关键词句子。换关键词或页面会重置游标。
- 搜索失败时清空当前页面，防止意外读取旧页面。
- 请求及原始返回内容会缓存在该实验目录的 `wiki_cache/`，含请求 URL 与首次获取时间；同一目录续跑可复用。不同运行的在线页面可能变化。
- 每题默认最多 7 次模型调用；格式错误也占用步数。达到上限则记为失败，不强行编出正确答案。

## 8. 冻结设置，运行评测

只在 dev10 上调试。确定提示词和参数后，再对 eval50 跑三组：

```bash
python3 react_lab.py run --data data/eval50.json --env wiki --methods direct cot react --limit 50 --seed 233 --max-steps 7 --max-tokens 1024 --out runs/06-eval50
```

可选再加 Act-only，使用一个新输出目录完整运行四组：

```bash
python3 react_lab.py run --data data/eval50.json --env wiki --methods direct cot react act --limit 50 --seed 233 --out runs/07-eval50-four
```

| 组别 | 允许读什么 | 输出形式 |
| --- | --- | --- |
| direct | 问题、固定示例 | Final: 简短答案 |
| cot | 同上，无工具 | 简短解题说明 + Final |
| react | 问题、交互示例、实际工具观察 | 简短 Thought + 一条 Action |
| act | 问题、相同交互示例去掉 Thought、实际观察 | 一条 Action |

CoT 与 ReAct 中记录的是模型生成的可见文本，不等于读取模型内部思维。这里的比较是不同提示与交互机制的对照，ReAct 总调用与 token 消耗可能更高，不能声称计算预算完全相同。模型与接口设置保持一致，完整成本差异需要结合服务商账单分析。

先小规模试跑，再决定是否扩大到 500 道。即使 temperature=0，服务端更新、采样和在线资料变化也可能影响结果；固定随机种子只固定抽样顺序，不保证模型输出完全一致。

## 9. 查看结果与续跑

每个运行目录包含：

| 文件 | 看什么 |
| --- | --- |
| manifest.json | 数据/代码哈希、完整提示词、模型名、参数、题目 ID 顺序 |
| records/*.json | 每题答案、标准答案、状态、轨迹、token、耗时 |
| results.csv | 逐题对照，可用表格软件打开 |
| summary.md / summary.json | 每组 EM、F1、工具调用、失败数 |
| wiki_cache/ | 在线检索原始响应，便于检查证据 |

手动重新生成报告：

```bash
python3 react_lab.py report --out runs/06-eval50
```

中断后，使用**完全相同的原命令**并加 `--resume`：

```bash
python3 react_lab.py run --data data/eval50.json --env wiki --methods direct cot react --limit 50 --seed 233 --max-steps 7 --max-tokens 1024 --out runs/06-eval50 --resume
```

完成写入的逐题记录都会跳过，包含失败记录。配置、数据、代码或提示词发生变化时，续跑会拒绝混用，必须使用新的 `--out`。API 错误会提前停止以避免对全部题目重复失败；修复配置后使用新目录重跑。程序会重试少数网络/限流/服务端错误，重试可能产生额外费用，`llm_calls` 是逻辑调用次数，不含底层 HTTP 重试次数。

部分运行也会生成报告。比较前确保每组已运行数等于计划数，题目相同；所有异常、格式失败和步数耗尽都按 0 分计入已运行样本的指标分母，不能删掉失败题后汇报更高分。

评分只包括答案 EM 和 token F1：大小写、英文冠词、标点、空白标准化后比较，yes/no/noanswer 有特殊处理，语义别名不会自动算同义。它不是中文分词指标，也不是 HotpotQA supporting-facts 或 joint 得分。

至少找出：

2. 一道 ReAct 错误的题（如有）：搜索、工具、证据理解还是答案格式出错？

`runs/` 默认不提交，防止把大量缓存与临时结果上传。完成后可在本目录新建 `实验记录/2026-xx-xx-第一次实验/`，复制选定的 summary、manifest、案例轨迹与填写后的报告，再从 paper 仓库提交。检查文件里没有密钥后同步。

## 11. 常见问题

| 现象 | 处理 |
| --- | --- |
| HTTP 401 / 403 | 检查密钥、权限、服务地址；维基百科 403 则检查该站网络访问 |
| HTTP 400 | 核对模型 ID、token 字段；不支持 temperature 时设 omit |
| HTTP 429 | 降低运行量，检查余额/限流，稍后再跑 |
| 连接失败或超时 | 检查网络；需要代理时在 .env 设置 HTTPS_PROXY，本机端口以实际配置为准 |
| 无可见文本 | 检查模型是否返回 content，或提高输出预算；代码不读取私有 reasoning 字段 |
| format_errors 多 | 看 raw_output，检查提示格式；修改提示词后换新目录 |
| 一直搜索同一实体 | 看轨迹；在调试集上修改提示，明确避免重复检索，再冻结设置 |
| 返回 No more results | 关键词不在当前页面，或已遍历匹配句；需要换关键词/实体 |
| EM=0 但答案似乎正确 | 检查别名、冗长回答、格式和参考答案，保留原始机器评分，另写人工分析 |
| 输出目录已存在 | 换目录，或用相同配置加 --resume |
