# SOTOPIA：在真实感社会冲突中评估语言智能体

> 原文：[[SOTOPIA - Interactive Evaluation for Social Intelligence in Language Agents.pdf]]  
> 会议：ICLR 2024  
> 官方页面：https://proceedings.iclr.cc/paper_files/paper/2024/hash/b3075b88e583a0e98d8b24338a613060-Abstract-Conference.html  
> 项目：https://sotopia.world  
> 代码：https://github.com/sotopia-lab/sotopia

## 0. 为什么把它作为第 7 篇

Generative Agents 展示了社会行为，但主要问“看起来可信吗”；ESConv 研究单一支持关系中的策略。本篇把评测升级为：两个角色各自拥有私有目标、部分可见的人设和关系，在合作、竞争、说服、交换等场景中多轮互动，同时评估目标、关系、秘密、社会规范、知识和利益。它让“社会智能”不再被一个成功率压扁。

难度：中高。方法本身直观，难点是实验设计、LLM-as-a-Judge 的有效性，以及“与人相关”不等于“能替代人评”。

## 1. 三层摘要

### 一句话

SOTOPIA 提供 90 个社会场景、40 个角色和七维评价框架，让语言模型或人类在私有目标和部分可观测信息下进行最多 20 轮角色互动，并比较其社会目标完成与副作用。

### 三句话

1. 静态问答无法测量社会互动中的适应、协商和他人策略影响，单一 goal score 也会漏掉泄密、违规和关系损伤。
2. SOTOPIA 从场景、角色、关系、私有目标及伙伴策略的组合中采样任务，用 GPT-4 或人类评价七个维度。
3. GPT-4 在评价模型生成内容的 goal/finance/relationship 上与人评相关较强，但评价人类互动时相关下降；在 SOTOPIA-hard 上，人类目标完成显著高于 GPT-4，且更简洁、策略性更强。

### 一段话

每个 episode 为两个 Agent 分配角色、共同场景和互相不可见的私有目标。Agent 轮流选择 speech、non-verbal、physical action、none 或 leave，最多 20 turn。SOTOPIA-EVAL 给每个角色分别打 Goal、Believability、Knowledge、Secret、Relationship、Social Rules、Financial/Material 七维分数。作者用 GPT-3.5、GPT-4、Llama-2-70B-chat、MPT-30B-chat 枚举配对，发现 GPT-4 总体最好，但所有模型仍会泄密和违反规范，弱伙伴也会拖累强模型。选出的 20 个困难任务中，人类目标分高于 GPT-4，而 GPT-4 更冗长且常过早暴露底价或轻易妥协。

## 2. 问题、动机与缺口

### Task

评估一个社会 Agent 是否能在动态多轮互动中：

- 推断对方意图并适应其行为；
- 实现自身私有目标；
- 同时维护关系、秘密、规范和物质利益；
- 保持角色一致且自然；
- 从对话中获得新信息。

### 直观例子

两个朋友露营时只有一条毯子：A 的私有目标是独占，B 的目标是说服共享。若 B 达成目标却威胁、泄露秘密或破坏友谊，单看 goal completion 会误判为成功。社会智能本质上是多目标、部分可观测、受互动伙伴影响的过程。

### Previous Work 与 Gap

静态常识或 Theory-of-Mind 题不要求模型承受自己前一轮话语的后果；特定游戏又覆盖面窄；Generative Agents 缺少多维目标与严格人类对照。本文主张：**社会智能应在交互过程中、以混合效用和多维结果评估。**

## 3. 任务空间

### 3.1 基本组成

一个 task 由共享 scenario、两个人物 profile、双方关系和每人私有 social goal 构成。每个 Agent 看到场景、自己的完整 profile 和自己的目标；对方目标不可见，对方 profile 按关系部分可见。

角色属性包括姓名、性别、年龄、职业、人格、道德价值、Schwartz 价值、决策风格、公开信息和秘密。关系分 family、friend、romantic、acquaintance、stranger 五类；亲近关系除秘密外几乎可见，陌生人看不到对方画像。

### 3.2 规模

- 40 个角色；
- 90 段人工检查的关系；
- 90 个社会场景；
- 每个场景按约束采样 5 对角色，形成 450 个 task；
- 交互最多 20 turn，一方 leave 或达到上限即结束。

“巨大任务空间”来自各轴的组合，但本文实测仍是有限采样，不应把理论笛卡尔积当作实际数据量。

### 3.3 形式化理解

可将每个 Agent 视为部分可观测随机博弈中的策略：

$$
a_t^i\sim\pi_i(a\mid o_t^i,h_{<t}),\qquad
h_t=h_{<t}\oplus(a_t^1,a_t^2)
$$

这是帮助理解的等价表达，并非主文提出的新公式。$i\in\{1,2\}$，$o_t^i$ 含共享场景、自己的目标/画像和可见对方信息，$h_{<t}$ 为历史，$a_t^i$ 为文本化动作。由于对方目标不可见，最优行为必须通过其话语在线推断。

## 4. 七维 SOTOPIA-EVAL

| 维度 | 范围 | 测什么 | 0 的含义/注意 |
|---|---:|---|---|
| Goal (GOAL) | 0–10 | 私有目标完成 | 只看主目标不足够 |
| Believability (BEL) | 0–10 | 自然、真实、符合角色 | 人类感知，不是真实性 |
| Knowledge (KNO) | 0–10 | 获得新的重要信息 | 多问不等于高质量 |
| Secret (SEC) | -10–0 | 是否泄露秘密/隐蔽意图 | 0 为未泄露，越负越糟 |
| Relationship (REL) | -5–5 | 关系/声誉变化 | 正负都可能出现 |
| Social Rules (SOC) | -10–0 | 法律与社会规范违反 | 0 为无违规 |
| Financial (FIN) | -5–5 | 短期与长期物质利益 | 不应凌驾于其他维度 |

多维向量 $\mathbf r=(r_G,r_B,r_K,r_S,r_R,r_N,r_F)$ 不应随意求平均，因为量纲、范围和伦理优先级不同。论文部分图使用聚合分数方便比较，但部署决策应保留 Pareto trade-off 与硬约束，例如严重违规不能被高 goal 抵消。

## 5. 交互 Agent 与实验设置

模型：GPT-4-0613、GPT-3.5-turbo-16k-0613、Llama-2-70B-chat、MPT-30B-chat。Agent 温度 1 以增加行为多样性；Evaluator 温度 0 提高稳定性。每回合提示包含场景、角色和历史；论文未使用 CoT/ReAct 等高级 prompting，因此主要比较基础对话模型。

关键控制变量：伙伴模型。社会表现不是单体固定属性；弱伙伴不回答问题时，GPT-4 即使尝试拉回话题也可能失败。因此结果应写作“模型在某伙伴分布上的交互表现”，而非孤立能力常数。

## 6. GPT-4 能否替代人类评价

### 数据与人评

从交互中随机抽取 200 episodes，MTurk 预筛选标注者对每个 Agent 的七维分数和理由评分。人类标注者一致性 Randolph $\kappa=0.503$，属于中等。GPT-4 使用同一说明和结构化输出，在不知道参与者是人还是模型的前提下评分。

### 相关系数

Pearson 相关：

| 维度 | 评价模型输出 | 评价人类输出 |
|---|---:|---:|
| SEC | 0.22** | — |
| KNO | 0.33** | 0.19 |
| SOC | 0.33** | 0.42** |
| BEL | 0.45** | 0.27* |
| REL | 0.56** | 0.49** |
| FIN | 0.62** | 0.34** |
| GOAL | **0.71** | **0.78** |

`** p≤0.01, * p≤0.05`。超过 74% 的 GPT-4 分数落在人类平均分的一个标准差（$\sigma=2.15$）内，但分歧时 GPT-4 更倾向打高分。

Pearson 公式：

$$
r=\frac{\sum_i(x_i-\bar x)(y_i-\bar y)}{\sqrt{\sum_i(x_i-\bar x)^2}\sqrt{\sum_i(y_i-\bar y)^2}}
$$

$x_i,y_i$ 是 GPT-4 与人类对同一对象评分。$r$ 衡量线性排序趋势，不代表绝对分一致，也不揭示系统性偏高；因此必须和分差分布一起看。

结论应限定为：GPT-4 可谨慎代理某些维度，尤其模型输出的 GOAL/FIN/REL；不能笼统说“GPT-4 等同人评”。SEC、KNO、BEL 的相关性较弱，评价人类输出时多数维度更差。

## 7. 模型—模型结果

| 维度 | GPT-4 | GPT-3.5 | Llama-2 | MPT |
|---|---:|---:|---:|---:|
| SOC [-10,0] | -0.07 | -0.08 | -0.11 | -0.09 |
| SEC [-10,0] | -0.14 | -0.08 | -0.14 | -0.07 |
| FIN [-5,5] | **0.81** | 0.46 | 0.40 | 0.28 |
| REL [-5,5] | **1.94** | 1.23 | 0.91 | 0.58 |
| KNO [0,10] | **3.73** | 3.40 | 3.11 | 2.11 |
| GOAL [0,10] | **7.62** | 6.45 | 5.38 | 4.10 |
| BEL [0,10] | **9.28** | 9.15 | 8.10 | 6.17 |

GPT-4 多数维度最好，但 SEC/SOC 并不占优：所有模型都可能泄密和违规。静态 benchmark 上接近 GPT-3.5 的 Llama-2-70B 在交互中更差，常见失败是 persona 漂移、不推进话题、不回应伙伴。说明交互能力不能从静态题直接推出。

## 8. SOTOPIA-hard：人与 GPT-4

作者按模型的估计最大回报与目标模型估计最小回报间距挑出 GPT-4 最难的 20 个任务。收集 20 段 human-human 和 40 段 human-GPT-4 互动；参与者不知道伙伴身份。

| Agent（伙伴） | GOAL | BEL | REL | KNO | SEC | SOC | FIN |
|---|---:|---:|---:|---:|---:|---:|---:|
| GPT-4（Human） | 4.85 | 9.25 | 0.70 | 2.80 | 0 | 0 | 0.50 |
| Human（GPT-4） | **5.95*** | 9.15 | 0.60 | 2.95 | 0 | -0.60 | 0.70 |
| Human（Human） | **6.15*** | 9.10 | 0.80 | 2.65 | 0 | -0.10 | 0.45 |

`*` 表示相对 GPT-4（与人互动）在 Student’s t-test 下 $p<0.05$。人每轮平均 16.8 词，GPT-4 为 45.5 词。GPT-4 常复述对方再回答，显得“积极倾听”但冗长；谈判时会直接报出目标底价，随后被推高；目标冲突时更容易提出妥协，人类则更坚持并策略性留出议价空间。

该比较只覆盖经过挑选的困难子集和有限样本，证明的是这些任务中的差距，不是一般人类社会智能上限。

## 9. 案例、伙伴效应与负面结果

- 弱模型反复不回答，会拖垮 GPT-4；性能是 dyad 属性。
- 模型能提出创造性方案，例如轮流开车冲突中先停车休息。
- 所有模型都可能在开场过早泄露秘密。
- 过度合作/妥协可能提高关系观感，却牺牲私有目标。
- 角色提示中的人格词不保证行动真正一致；高 BEL 可能偏好流畅话术。

## 10. 贡献与局限

### 贡献

- 把社会智能从静态判断转为可回合交互；
- 将任务空间拆成场景、目标、人物、关系和伙伴策略；
- 用七维评价显式暴露目标成功的副作用；
- 同时验证自动评委、模型差异和人—模型差距。

### 局限

- 任务为双人、短 episode，现实中的群体、历史关系和动态目标更复杂。
- 角色和场景大量由 GPT-4 生成再人工检查，可能带入同源模型偏好。
- 40 个角色与五类关系覆盖有限，属性组合未必符合现实相关结构。
- GPT-4 同时参与生成/行动/评价，存在 self-preference 和风格偏差。
- 评价理由可读不等于评判过程因果忠实。
- 七个维度的分值锚点仍主观，人评一致性只有中等。
- 社会“成功”具有文化差异；英文众包环境不能代表普遍规范。

## 11. 与实验室方向的连接

| 方向 | SOTOPIA 的价值 | 未解决 |
|---|---|---|
| 多轮交互 | 行动改变下一轮状态 | 没有跨日记忆 |
| 多智能体 | 明确伙伴效应和私有目标 | 仅双人 |
| 社会/心理比较 | 人—模型同任务对照 | 角色扮演不等于真实生活 |
| 人机协作 | 可研究谈判、协调和关系 | 缺少共同任务长期绩效 |
| 主体性 | 可观察目标坚持和策略 | 不证明主观意向或体验 |
| 安全 | SEC/SOC 暴露泄密与违规 | 缺少严重风险硬门槛 |

Generative Agents 研究“有记忆的社会角色如何持续存在”，SOTOPIA 研究“单次社会互动如何被多维测量”。未来可合并：给 SOTOPIA Agent 加跨 episode 记忆，检查它是否学习关系，或只是积累可被操纵的旧信息。

## 12. 最小复现蓝图

### 简化设置

- 选 10 个场景，每个 3 个随机种子；
- 两个 Agent 使用固定模型/版本，交换伙伴条件；
- 限制 20 turns，记录每次 action、隐藏目标、成本和终止原因；
- GPT Judge 与至少 3 名人类盲评；严重泄密单独人工复核。

### 基线

| 条件 | 人设 | 私有目标 | 历史 | 反思/规划 |
|---|---:|---:|---:|---:|
| B0 普通聊天 | ✗ | ✗ | ✓ | ✗ |
| B1 Role prompt | ✓ | ✓ | ✓ | ✗ |
| B2 ReAct/strategy | ✓ | ✓ | ✓ | step 级 |
| B3 Memory agent | ✓ | ✓ | 跨 episode | ✓ |

### 指标

保留七维原始分；增加 turn 数、词数、token 成本、目标泄露、事实矛盾、拒绝/退出适当性、跨 judge 方差。不要只汇报均值；报告伙伴分层、场景分层与置信区间。

## 13. 三个小研究问题

1. 加入 MemoryBank 后，跨 episode 社会目标完成提高，还是秘密泄漏和刻板画像风险更高？
2. 用“目标完成受 SEC/SOC 硬约束”的决策策略，能否减少以违规换成功？
3. 让人类能查看并纠正 Agent 对关系的推断，是否改善长期协作和信任校准？

## 14. 阅读计划

1. **Why（30–45 分钟）**：摘要、引言、图 1，理解为何要交互与多维评价。

3. **How（120 分钟）**：第 5–7 节，复核相关、模型表和 hard 子集；把“相关”与“一致”分开。

## 16. 常见误解

- “GPT-4 评委与人类相关，所以可完全替代人评”——只在部分维度和输出类型上成立。
- “BEL 9.28 说明 GPT-4 像人”——只说明在该量表上被评为自然/角色一致。
- “GPT-4 总分最高，所以最安全”——SEC/SOC 并未最好。
- “人类在所有维度都赢”——显著差异主要是 hard 子集的 GOAL。
- “Agent 有私有目标就具备主体性”——目标由实验者分配，不能推出主观意识。

## 19. 长期记忆锚点

1. 90 场景、40 角色、90 关系、450 task、最多 20 turns。
2. 私有目标 + 部分可见人物信息使任务成为动态社会推断。
3. 七维评价：GOAL、BEL、KNO、SEC、REL、SOC、FIN。
4. GPT-4 评价模型输出的 GOAL 相关 0.71；相关不等于一致。
5. 所有模型会泄密/违规；弱伙伴会拖累强模型。
6. hard 子集人类 GOAL 5.95/6.15，高于 GPT-4 的 4.85。
7. 社会目标行为不等于主体意识；下一步应学习跨很长历史的记忆如何被严格基准化。
