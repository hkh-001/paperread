# 页面状态提示实验结论

2026-10-24：完成十题开发对照及新五十题独立配对，各题两个版本，共 120 次真实作答。**本轮不足以证明页面状态提示有稳定的整体收益，默认保留原版。**

## 新五十题结果

| 指标 | 原版 ReAct | 页面状态版 |
| --- | --- | --- |
| 精确答对 | 21/50（42%） | 23/50（46%） |
| 答案 F1 | 0.574 | 0.590 |
| 空页面 Lookup（主指标） | 2 次 | 1 次 |
| 步数耗尽 | 8 题 | 10 题 |
| 格式错误 | 17 次 | 7 次 |
| 模型调用 | 212 次 | 207 次 |
| 工具动作 | 153 次 | 160 次 |
| 输入＋输出 token | 114,924 | 138,767（约 +20.7%） |

状态版独对 3 题，原版独对 1 题，净多 2 题；精确 McNemar 双侧 p=0.625，未显示显著正确率差异。三道新增匹配中，两道涉及 CTV 全称/简称、Merck 公司名称完整性，不能全部解释为知识或推理能力提升。原始 EM/F1 不改分。

主指标仅少一次，仍有模型在看到 `current_page=null` 后执行 Lookup 的反例。提示可能影响检索路线和输出格式，但不能保证遵守状态或合理停止。调用次数略少而 token 更多，也说明调用量不能替代成本统计。没有估算金额。

本轮 191 次真实维基 HTTP 请求全部成功，0 次 429、额外重试或工具故障；其余为缓存复用。模型、题目、步数、工具语义和评分保持固定，只有页面状态反馈开关不同。原版与状态版在同一批新题上同期比较，不能把此处 46% 与旧五十题的 46% 当作同一批结果。

## 十题调试

两版均 6/10、F1 0.644；模型调用 47→41，格式错误 6→2，但两版空页面 Lookup 都为 0，不能据此认定目标故障被消除。十题为已知开发题，不算独立验证。

## 实现与使用决定

- 新增 `--state-feedback`，在问题、观察和格式提醒中反馈真实当前页面。默认关闭，不改变原版消息。
- 新增配对运行器，冻结题目、代码和参数，交替运行顺序，自动检查与旧题的重叠。
- 29 项离线软件检查通过，覆盖状态清空、非法输出隔离、原版不受影响、答案隔离、续跑与配置变更拒绝。
- 暂不扩大题量或叠加其他修改。若继续研究，优先把“可用动作约束”或“停止条件”作为单独新实验；需要另设新题，不能在看过的五十题上调完再声称独立增益。
